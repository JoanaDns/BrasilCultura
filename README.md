# CulturaBrasil

Projeto React + Vite sobre a cultura e culinária brasileira.

## Instalar e executar

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Imagens

Todas as fotografias ficam em `public/imagens/` e usam `.jpg`.

Para trocar uma fotografia, substitua o JPG mantendo o mesmo nome. Não é necessário importar a imagem nem editar componentes React. Consulte `IMAGENS.md` para ver as instruções e exemplos.

O mapa do Brasil permanece em SVG por ser um desenho vetorial interativo; as fotografias são JPG.
